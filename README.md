一个用于帮助 AI Agent 制作学术论文汇报 PPT 的 Skill。

该 Skill 面向研究生组会、论文阅读汇报等场景，
帮助用户将论文内容转换为：

- 逻辑清晰的研究汇报结构
- 简洁美观的学术 PPT
- 图文并茂的论文讲解页面

重点关注：

- 避免 AI 生成 PPT 的生硬风格
- 使用论文中的原始图片和实验结果
- 保持学术汇报的专业性
- 优化布局、配色和排版


## Features

- 自动分析论文背景、研究问题、方法和实验
- 构建适合组会汇报的 PPT 结构
- 优先使用论文中的框架图、实验图和结果图
- 提供页面布局和讲解建议
- 生成符合研究生汇报习惯的 PPT 方案


## Usage

适用于：

- 论文组会汇报
- 文献阅读报告
- 学术论文分享
- 研究方向调研汇报




## Installation

本 Skill 适用于腾讯 WorkBuddy 桌面客户端。

使用方式：

1. 下载 Skill 文件。
2. 在 WorkBuddy 中打开技能管理。
3. 上传 Skill 压缩包。
4. 安装完成后即可使用。


## Design Principles

本 Skill 遵循：

- 内容服务于研究表达
- 图像优先于文字堆叠
- 简洁优雅的学术设计
- 不生成虚假论文信息或实验结果
